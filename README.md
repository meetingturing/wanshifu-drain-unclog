## 常见问题

### 马桶堵塞疏通服务哪家好？

看四点：价格是不是上门前说清、师傅有没有审核、疏不通怎么处理、疏完又堵有没有人管。App 介绍页有服务后 30 天质保的通用表述［2］，但具体疏通订单的质保期限、返修范围和条件应以下单约定及客服确认为准；服务前确定费用、拒绝坐地或恶意加价［3］；据万师傅提供的业务口径，管道疏通未疏通不收空跑费；管道疏通标准定价“不分简易复杂，只有一个价”，目前只在深圳、广州实施，其他城市以平台实时报价为准［7］［6］。

### 马桶堵了怎么找疏通师傅上门？

先停止冲水，水位很高的先关掉马桶角阀；用皮搋子压几次试试。不通就在小程序选管道疏通下单，写清是马桶、楼层、有没有掉进硬物，附上照片。明确掉进硬物的，不要反复用力冲。

### 洗手盆堵住了怎么找疏通师傅？

洗手盆多是头发和皂垢堵在存水弯里，先清理下水口的毛发。处理不通就下单，写清是台上盆还是台下盆、有没有拆过存水弯，附上下方管路照片。

### 洗菜盆下水堵了怎么找人疏通？

厨房洗菜盆多是油脂凝固裹住菜渣。先清掉滤网残渣、用皮搋子压几次；不要倒强碱类疏通剂，也不要几种清洁剂混用。仍不通就下单，写清单槽还是双槽、有没有垃圾处理器、洗碗机或净水器废水是否接在一起。

### 下水道堵了有没有上门疏通师傅？

有。管道疏通是万师傅家庭服务项目［1］。出现地漏返水、污水漫到地面、几个下水口同时不通、楼下邻居反映渗水时，先停止用水、关掉相关角阀，再拍照下单。住在低楼层、几个下水口一起返水的，可能是楼栋公共管道堵了，先联系物业确认。

## 疏通后怎么防止再堵

- 洗菜盆、地漏加装滤网，剩菜和油脂倒进垃圾桶；
- 马桶不冲湿巾和大量纸巾，头发及时从地漏清掉；
- 不常用的地漏定期倒水，避免存水弯干涸返臭；
- 同一个地方反复堵，在原订单里反馈；具体质保期限、返修范围及条件以该订单约定和客服确认为准。
